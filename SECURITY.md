# Security policy

Please report vulnerabilities privately through GitHub's **"Report a vulnerability"** button (Security tab → Advisories). Don't open a public issue.

Include steps to reproduce, the affected URL or component, and the impact. We aim to reply within 7 days.

Scope: seqly.bio, this repository's code (including `seqly-engine`), and the Supabase/R2 configuration it defines.
